# Rasmlar

Rasmlarni shu papkaga quyidagi nomlar bilan qo'ying, sayt ularni o'zi topadi:

- `maktab.jpg` — bosh sahifadagi maktab binosi rasmi (yotiq, 4:3 nisbatda yaxshi ko'rinadi)
- `direktor.jpg` — direktor rasmi (tik, 4:5 nisbatda)
- o'qituvchilar rasmi — istalgan nom bilan, `index.html` dagi `photo: "rasmlar/nomi.jpg"` qatoriga yoziladi

Rasm qo'yilmagan bo'lsa, o'rnida chizma yoki bosh harflar ko'rinadi.
Odamlar rasmini faqat o'zlarining roziligi bilan joylang.
